# PixelType — imagem para ASCII

Uma mini aplicação web para transformar imagens em arte ASCII, com conversão inteiramente local no navegador.

O projeto está separado em `index.html` (estrutura), `style.css` (visual) e `script.js` (conversão e interações).

## Como usar

Abra `index.html` no navegador, escolha ou arraste uma imagem e ajuste a largura, o conjunto de caracteres e a inversão de tons. O resultado pode ser copiado ou baixado como arquivo `.txt`.

Não precisa instalar dependências nem iniciar um servidor. São aceitas imagens PNG, JPG, WEBP, GIF e BMP de até 20 MB.
